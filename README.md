# dsh-session-cost

Плагин для DeepSeek Harness: показывает примерную стоимость сессии рядом с полем
ввода и раскрывает её по ключам и периодам.

Считается по журналу сессии: провайдерские счётчики токенов
(`assistant/message`, `assistant/attempt`) умножаются на опубликованный прайс
модели. Повторный расчёт за тот же ход заменяет предыдущий, а не складывается с
ним — иначе счётчик двоился бы на стриминговых сэмплах.

## Что показывает

- **Пилюля** — итог сессии в рублях.
- **Панель по клику** — статьи расхода (вход мимо кэша, вход из кэша, запись
  кэша, выход), итог, вторая строка в долларах.
- **По ключам** — отдельная строка на каждый API-ключ, который тратил токены, с
  подписью из конфига (`DeepSeek · DEEPSEEK_API_KEY`).
- **Расход по периодам** — таблица «Эта сессия / Сегодня / 7 дней / 30 дней /
  Всего» по ключам. Первая колонка — текущая сессия, остальные читаются из кэша
  проекций всех сохранённых сессий машины; пустой период показывается прочерком.
- **Делегации** — работа субагентов входит в расход сессии, которая их вызвала,
  с пометкой «Включая делегации: N».

## Прайс

Модель называет свою валюту и свой набор ставок:

```js
'gemini-3.1-pro-preview': {
  provider: 'google', currency: 'USD',
  input: 2, output: 12, cacheRead: 0.2, cacheWrite: 0,
  tiers: [{ inputTokensAbove: 200_000, input: 4, output: 18, cacheRead: 0.4, cacheWrite: 0 }],
}
```

- DeepSeek идёт со своими пиковыми и непиковыми часами по Пекину в CNY;
- Gemini — по снапшоту каталога `@earendil-works/pi-ai`, который использует сам
  маршрут, в USD;
- модель, которой нет в таблице, помечается как непроценённая, а не считается по
  чужому тарифу;
- валюта без курса тоже становится непроценённой, а не нулевой.

Курсы, подписи ключей и язык панели задаются конфигом:

```yaml
- id: session-cost
  name: "@local/session-cost"
  config:
    rates: { CNY: 12.0557, USD: 80.53 }   # рублей за единицу валюты прайса
    secondary: { currency: USD, symbol: "$" }
    providers:
      google: { label: Google · GOOGLE_API_KEY }
    language: ru        # auto | ru | en | zh
    lifetime: { enabled: true }
```

## Установка

```sh
git clone <этот репозиторий>
cd dsh-session-cost
./install.sh          # или ./install.sh --check, чтобы только посмотреть план
```

Скрипт линкует пакет в `node_modules` профиля, добавляет имя в
`dsh.profile.bundles` и вписывает блок конфига в `cordis.patch.yml` между
маркерами `dsh-local-plugins`. Затем перезапустите GUI: Loader собирает дерево
при старте. Правки конфига подхватываются пересборкой профиля, правки кода —
только перезапуском.

## Проверки

```sh
cd session-cost && npm test     # 41 проверка свёртки + 32 проверки панели
```

Хостовые проверки гоняют свёртку на синтетических событиях: тарифы обеих валют,
длинный контекст, замена повторного расчёта, ретраи, форк-префикс, непроценённые
токены, суммы по ключам и периодам. Клиентские — собирают панель через
поддельный React и сверяют подписи, суммы и русский вариант.

`node price-session.mjs путь/к/session.jsonl [inheritedEventCount]` считает
стоимость готового журнала тем же кодом. Для форк-сессии вторым аргументом
передайте `inheritedEventCount`, иначе унаследованный префикс родителя попадёт в
счёт.

## Ограничения

- Это оценка по прайс-листу, а не биллинг: скидки, промо и округления платформы
  не учитываются.
- Периоды читаются из контрольных точек проекций, поэтому свежие секунды
  догоняют с задержкой до следующего сохранения активной сессии.
- Сессия целиком относится к периоду, в котором началась: кэш хранит одну сумму
  на сессию, не по запросам.
- Внешние субагенты (ACP/Codex/Claude Code) локального журнала не имеют и в
  сумму не входят.
