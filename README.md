# dsh-session-cost

Плагин для DeepSeek Harness: показывает примерную стоимость текущей сессии рядом
с полем ввода — в рублях, с расшифровкой по статьям и второй строкой в долларах.

Цифра считается по журналу сессии: провайдерские счётчики токенов
(`assistant/message`, `assistant/attempt`) умножаются на опубликованный прайс
DeepSeek (`deepseek-flash`, `deepseek-v4-pro`), с учётом пиковых и непиковых
часов по Пекину. Повторный расчёт за тот же ход заменяет предыдущий, а не
складывается с ним — иначе счётчик двоился бы на стриминговых сэмплах.

Если у сессии есть локальные субагенты, пилюля показывает сумму: расход
родительской сессии плюс все дочерние сессии (рекурсивно). Дети находятся по
проекции `subagentCatalog`, их стоимость читается из проекции `sessionCost`
каждой дочерней сессии; живые обновления приходят вместе с control-кадрами
Session Controller. Внешние субагенты (ACP/Codex/Claude Code) локального журнала
не имеют и в сумму не входят — в панели это отмечено.

Это оценка по прайс-листу, а не биллинг: точные суммы — на платформе DeepSeek.

## Установка

```sh
git clone <этот репозиторий>
cd dsh-session-cost
./install.sh          # или ./install.sh --check, чтобы только посмотреть план
```

Скрипт делает три вещи в профиле `web` (переопределяется `DSH_PROFILE` или
`DSH_PROFILE_DIR`):

1. линкует пакет в `node_modules` профиля;
2. добавляет имя в `dsh.profile.bundles`;
3. вписывает блок конфига в `cordis.patch.yml` между маркерами
   `dsh-local-plugins` (старое содержимое сохраняется, делается `.bak`).

Затем перезапустите GUI: Loader собирает дерево при старте.

## Обновление

```sh
git pull && ./install.sh
```

Правки кода подхватываются симлинком, но новый модуль загружается при
перезапуске GUI. Повторный `install.sh` идемпотентен: если ничего не изменилось,
файлы не перезаписываются.

## Настройка

Конфиг живёт в блоке `profile/cordis.patch.yml` и версионируется вместе с кодом:

```yaml
- id: session-cost
  name: "@local/session-cost"
  config:
    rate: 12.0557        # ₽ за 1 ¥ (курс ЦБ)
    secondary:
      currency: USD
      symbol: "$"
      rate: 0.1497       # $ за 1 ¥
```

Прайс задаётся в `session-cost/index.js` (`DEFAULT_MODELS`) в юанях — как его
публикует DeepSeek — и пересчитывается в валюту отображения на лету. Свои
тарифы можно задать через `config.models`:

```yaml
    models:
      deepseek-flash:
        miss: { idle: 1, peak: 2 }      # ¥ за 1M токенов
        hit: { idle: 0.02, peak: 0.04 }
        output: { idle: 4, peak: 8 }
```

Пиковые часы — Пекин, будни 09:00–12:00 и 14:00–18:00 (`peakHours`), выходные
всегда непик. Часовой пояс переопределяется `timeZone`.

## Субагенты

`sessionCost` остаётся проекцией одной сессии. Пилюля складывает дерево:
родитель + все локальные потомки, найденные по `subagentCatalog`. Обход
рекурсивный, поэтому субагент субагента тоже учитывается.

- Унаследованный форк-префикс не считается повторно: проекция начинает счёт
  после `inheritedEventCount`, поэтому стоимость родителя не удваивается.
- Дочерние сессии, которых ещё нет в браузере, подтягиваются через
  `ctx.sessions.refreshProjections()`.
- Живые дочерние сессии обновляются control-кадрами Session Controller, без
  опроса.
- Внешние субагенты (`mode: 'external'`) не имеют локальной сессии и не
  оцениваются; панель пишет, сколько их.
- Если дочерняя сессия использует другой курс или валюту (например, конфиг
  менялся посреди работы), она исключается из суммы с пометкой.

## Проверки

```sh
node check-fold.mjs                       # 28 проверок: тарифы, замена, ретраи, валюты, форк-префикс
node check-tree.mjs                       # обход дерева, сумма, external, loading
node price-session.mjs путь/к/session.jsonl.zstd
```

Для форк-сессии вторым аргументом передайте `inheritedEventCount`, иначе
унаследованный префикс родителя попадёт в счёт.

## Ограничения

- Оценка по прайс-листу, а не счёт: скидки, промо и округления платформы не учитываются.
- Стоимость считается по модели, записанной в журнале; при смене модели посреди
  сессии каждая часть считается по своей модели, но агрегат общий.
- Внешние субагенты не учитываются: у них нет локального журнала (см. выше).
- Подписи в интерфейсе на английском: в клиенте DSH локали `en` и `zh`.
